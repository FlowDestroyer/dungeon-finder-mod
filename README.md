## 📖 About

Dungeon Finder predicts spawner dungeon locations from the world seed, highlighting them in the world with coloured boxes and listing coordinates in the HUD.

---

## ✨ Features
<a name="features"></a>

- **Spawner Type Filter** — find zombie, skeleton, or spider dungeons.
- **Coloured ESP** — boxes rendered around dungeons through terrain.
- **Coordinate List** — sorted by distance in the HUD.
- **Loot Table Preview** — shows expected loot per spawner type.
- **Chunk Range** — configurable search radius.
- **Export** — save dungeon list to file.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
